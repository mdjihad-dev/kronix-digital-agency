A modern and responsive digital agency website built from a Figma design using HTML5 and CSS3.

## 🌐 Live Website

[Visit Kronix Digital Agency](https://kronix-digital-agency.vercel.app)

## 🛠️ Technologies & Tools

- HTML5
- CSS3
- Figma
- Visual Studio Code (VS Code)

## ✨ Features

- Modern and clean UI
- Fully responsive design
- Figma-based implementation
- Semantic HTML structure
- Custom CSS styling
- Smooth and user-friendly layout

This project was created to practice converting a Figma design into a functional, responsive website using HTML and CSS.
